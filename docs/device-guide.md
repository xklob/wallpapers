# RGB Geometry wallpapers

Each pack contains three patterns for 603 model and screen profiles. Choose a screen and either Plain or RGB Border in the [wallpaper picker](https://wallpapers.klob.io/). Foldable covers, inner screens and orientations have separate entries.

Source-linked display dimensions are in `display-specs/`. The archive’s `catalog.json` lists the file path, preset and native pixel dimensions for each artwork. Models that share artwork appear in `device_aliases.json`. The website names each download for the model you select.

Camera rings are available on 111 screen profiles. Thirty use published cutout coordinates and 81 use estimates. The picker indicates estimated placements. Use `Camera_Ring_Adjuster.html` to personalize the ring. Pixel 11 Pro XL also supports status bar and home row outlines. Pixel Tablet offers a Home row outline in both orientations. Use the version without the Home row on the lock screen. See `Flagship_Support.md` for launcher and display fit details.
